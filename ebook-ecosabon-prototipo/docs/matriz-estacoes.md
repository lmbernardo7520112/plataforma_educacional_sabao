## Estação 1: Filtração e Preparo do Óleo Residual

`[DADOS FICTÍCIOS PARA TESTE]`

| Campo                      | Conteúdo                                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Nome da estação            | Filtração e Preparo do Óleo Residual                                                                       |
| Objetivo pedagógico        | Compreender a importância da purificação da matéria-prima e calcular a proporção óleo:solvente              |
| Conteúdo específico        | Filtração simples, cálculo de rendimento mássico, proporções e conversão de unidades (mL → g via densidade) |
| Materiais                  | Óleo de cozinha usado, filtro de papel/tecido, funil, béquer, balança, calculadora                          |
| Tempo                      | 20 minutos                                                                                                 |
| Mediação docente           | Circular entre os grupos. Perguntar: "Por que filtrar antes de reagir?". Validar cálculos de rendimento     |
| Avaliação                  | Registro no roteiro do estudante (proporção calculada + justificativa escrita)                               |
| Adaptação de baixo recurso | Substituir balança por medida volumétrica com copo graduado; usar coador doméstico ao invés de funil        |
| Anexo correspondente       | `anexos/roteiro-estudante-estacao-1.md`                                                                    |

## Estação 2: Reator de Saponificação — IoT vs Manual

`[DADOS FICTÍCIOS PARA TESTE]`

| Campo                      | Conteúdo                                                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Nome da estação            | Reator de Saponificação — IoT vs Manual                                                                                          |
| Objetivo pedagógico        | Comparar o processo de saponificação com e sem mediação tecnológica, identificando variáveis controladas                          |
| Conteúdo específico        | Reação de saponificação (triglicerídeo + NaOH → sabão + glicerol), estequiometria molar, controle de temperatura                 |
| Materiais                  | NaOH diluído, óleo filtrado, termômetro (ou sensor IoT), cronômetro, EPIs obrigatórios                                          |
| Tempo                      | 30 minutos                                                                                                                       |
| Mediação docente           | Demonstrar o procedimento seguro. Perguntar: "Que variáveis mudam entre o método IoT e o manual?". Supervisionar EPIs            |
| Avaliação                  | Tabela comparativa IoT vs Manual preenchida no roteiro + cálculo estequiométrico                                                 |
| Adaptação de baixo recurso | Sem sensor IoT: usar termômetro analógico e cronômetro do celular. Registrar manualmente no roteiro em vez de captura automática |
| Anexo correspondente       | `anexos/roteiro-estudante-estacao-2.md`                                                                                          |

## Estação 3: Controle de Qualidade — Teste de pH e Análise do Produto

`[DADOS FICTÍCIOS PARA TESTE]`

| Campo                      | Conteúdo                                                                                                       |
| -------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Nome da estação            | Controle de Qualidade — Teste de pH e Análise do Produto                                                       |
| Objetivo pedagógico        | Avaliar a qualidade do sabão produzido por meio de indicadores de pH e interpretar resultados quantitativos     |
| Conteúdo específico        | Escala de pH, indicadores ácido-base (fenolftaleína, papel indicador), faixa ideal para sabão (pH 8-10)        |
| Materiais                  | Amostras de sabão produzido, papel indicador de pH, fenolftaleína, água destilada, tabela de referência         |
| Tempo                      | 15 minutos                                                                                                     |
| Mediação docente           | Perguntar: "O que significa um pH acima de 10 para a pele?". Relacionar com excesso de NaOH na estequiometria  |
| Avaliação                  | Registro do pH medido + classificação (ácido/neutro/básico) + parecer sobre adequação do produto               |
| Adaptação de baixo recurso | Usar repolho roxo como indicador natural ao invés de fenolftaleína; substituir água destilada por água filtrada |
| Anexo correspondente       | `anexos/roteiro-estudante-estacao-3.md`                                                                        |

## Checklist Pré-Aula (para o professor)

- [ ] Os EPIs estão disponíveis e em quantidade suficiente para todos os grupos?
- [ ] O óleo residual foi coletado e armazenado adequadamente?
- [ ] A solução de NaOH foi preparada na concentração correta?
- [ ] Os roteiros dos estudantes estão impressos ou acessíveis digitalmente?
- [ ] O sensor IoT está carregado e funcional? (ou termômetro analógico disponível?)
- [ ] O ambiente está ventilado para a estação de saponificação?
- [ ] Os indicadores de pH estão dentro do prazo de validade?
- [ ] A organização da sala segue o diagrama de estações?
