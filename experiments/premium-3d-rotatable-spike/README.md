# Prova de Conceito (Spike) — Premium 3D Rotacionável Qualitativo

Este diretório contém uma prova de conceito isolada e experimental para testar a viabilidade de uma visualização didática rotacionável do Palco Molecular do **EcoSabon**.

---

## Finalidade do Spike
Este experimento demonstra a viabilidade de uma rotação didática multiângulo qualitativa e discreta utilizando apenas tecnologias web puras (SVG, CSS e vanilla JS), sem dependências pesadas, sem WebGL e sem risco de acessibilidade de tela ou impressão.

> [!WARNING]
> **Aviso Importante:** Esta é uma prova técnica isolada. Não está integrada ao e-book principal do EcoSabon. Não representa uma simulação científica/molecular validada, tratando-se apenas de um modelo demonstrativo qualitativo para estudo de viabilidade.

---

## Como Executar
1.  Abra o arquivo `index.html` contido nesta pasta diretamente no seu navegador.
2.  Use os botões de controle para rotacionar qualitativamente o modelo em quatro perspectivas didáticas (0°, 90°, 180° e 270°).
3.  Verifique a estabilidade do layout, tempo de carregamento instantâneo e conformidade de acessibilidade (leitura de tela e foco).
